# Module 1: Variables and Basic Data Types
In Python, a variable is a reserved memory location to store values. Unlike other languages, you do not need to declare the type of variable; Python determines it automatically based on the value you assign. For ML and AI, you will primarily deal with four basic data types: integers (whole numbers), floats (decimal numbers), strings (text), and booleans (True or False).

For example, if you are building a model to predict house prices, you might use an integer for the number of rooms, a float for the square footage, a string for the neighborhood name, and a boolean to indicate if the house has a garage.

# Integer
rooms = 3

# Float
square_feet = 1250.5

# String
neighborhood = "Green Valley"

# Boolean
has_garage = True

print(f"The house in {neighborhood} has {rooms} rooms and is {square_feet} sq ft. Garage: {has_garage}")
